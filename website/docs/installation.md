# Installation

## 1. Clone the repository

```bash
git clone git@github.com:abderrahmenlamloumi/OrionDB.git
cd OrionDB/orion-db
```

## 2. Fetch Go module dependencies

```bash
go mod download
```

Expected result:

- Go dependencies in `go.mod` and `go.sum` are available locally.
