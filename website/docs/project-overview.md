# Project overview

OrionDB is a telemetry ingestion and storage project written primarily in Go. The repository positions it as a systems engineering project for learning architecture trade-offs in modern observability platforms.

For safe usage, rely on implemented code paths and current commands listed in [API and command reference](./api-command-reference.md).
